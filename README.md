# Simon Says Game 🎮

A classic memory-enhancement game built using HTML, CSS, and Vanilla JavaScript. Test your memory by following an ever-increasing sequence of colors!

## 🚀 How to Play

1. **Start the Game**: Press any key on your keyboard to begin.
2. **Watch the Sequence**: The game will flash a button. Remember the color.
3. **Repeat the Pattern**: Click the buttons in the exact same order as they were flashed.
4. **Level Up**: Every time you successfully complete a sequence, the game adds a new step to the pattern.
5. **Game Over**: If you click the wrong color, the screen will flash red, and your final score (level) will be displayed.

## ✨ Features

* **Dynamic Leveling**: The difficulty increases as you progress.
* **Visual Feedback**: Buttons flash when selected by the game and when clicked by the user.
* **High Score Tracking**: Keeps track of your progress during the session.
* **Responsive Design**: Clean and simple UI that works on various screen sizes.

## 🛠️ Tech Stack

* **HTML5**: For the game structure.
* **CSS3**: For the layout, button styling, and "game over" animations.
* **JavaScript (ES6)**: For the game logic, sequence generation, and event handling.

## 📂 Project Structure

* `index.html` - The main entry point.
* `style.css` - Contains the visual design and animations.
* `app.js` - Contains the logic for the game flow.
